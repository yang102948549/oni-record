# ON생기부 · oni-record

ON생기부 Windows 설치 파일과 Oni Class · ON생기부 공용 나이스 확장프로그램을 배포하는 저장소입니다.

## 다운로드

- [전체 릴리스 및 설치 안내](https://github.com/yang102948549/oni-record/releases)
- [ON생기부 0.1.1-beta.1 Windows x64 설치 EXE](https://github.com/yang102948549/oni-record/releases/download/v0.1.1-beta.1/ONSaenggibu-0.1.1-beta.1-x64-setup.exe)
- [공용 나이스 확장 0.5.0 ZIP](https://github.com/yang102948549/oni-record/releases/download/v0.1.1-beta.1/OniClass-ONSaenggibu-NEIS-0.5.0.zip)

EXE를 내려받아 설치한 뒤 ON생기부를 실행합니다. 공용 크롬 확장을 설치·갱신하고 앱의 나이스 반영 → 연결 설정에서 확장 ID를 등록하세요. 이미 Oni Class와 함께 공용 확장을 사용 중이라면 기존 확장 폴더에 ZIP의 내용을 덮어쓴 뒤 확장 관리에서 새로고침합니다.

교과세특·자율활동·행동특성은 앱에서 선택한 학생 원문을 나이스 그리드에 반영하는 방식입니다. 엑셀 업로드를 거치지 않습니다. 현재 확장 지원 도메인은 충북 나이스(`cbe.neis.go.kr`)입니다.

현재 버전은 시험 배포입니다. 교과세특은 사용자 실사용 확인을 받았으며, 자율활동·행동특성은 모의 테스트를 통과했지만 실제 나이스 저장 검증이 더 필요합니다. 상세 검증 범위와 연결 방법은 각 릴리스의 안내서를 확인하세요.

이 저장소는 배포 파일과 안내서를 관리합니다. 학생 자료, 개인 설정, 연결 토큰은 포함하지 않습니다. Oni Class의 설치 파일과 자동 업데이트는 [oni-class](https://github.com/yang102948549/oni-class/releases)에서 별도로 관리합니다.
